# Personal Portfolio Website

Welcome to my personal portfolio website!

This repository contains the source code for my portfolio website, originally developed to showcase my work in data analytics, business intelligence, and data science.

The website brings together selected projects, their descriptions, visualizations, and links to detailed project demonstrations.

### 🌐 Live Website

[Visit My Portfolio Website](https://venkatramoju01.github.io/MyWebsite/index.html)

### 📂 Featured Projects

The portfolio includes projects covering:

- **Predictive Analytics:** Employee Turnover Prediction, Loan Default Prediction.
- **Machine Learning:** TikTok Video Classification, Taxi Fare Prediction.
- **Business Analytics:** Meta Ads Performance Analysis using Excel.
- **Text Analytics:** Reddit Sentiment Analysis using Hugging Face.

### 🛠️ Technologies

HTML, CSS, JavaScript, Python, and associated data analytics and machine learning tools.

### 📌 About

This portfolio represents an earlier phase of my professional journey, during which I focused on developing analytical, statistical, and data-driven problem-solving skills.

I continue to retain these projects as part of my learning and professional experience.
